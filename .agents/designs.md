# 我建議的統一設計規則

每顆馬卡龍都遵循同一套「甜點語法」：

**外殼＝專案的品牌與第一印象**
品牌成熟的專案直接使用現有品牌色；沒有品牌的，就用它解決的問題來選色。

**內餡＝專案真正做的事**
例如 Workshop 的餡要整齊分層，因為它會把龐大配方拆成可執行項目；LinkArray 的餡則可以從散亂節點重新排列。

**表面裝飾＝最值得被記住的一件事**
一張清單、一條界線、一隻鼠鼠、一隻獨角獸、一滴水，讓使用者即使忘記專案名稱，也記得「喔，是那顆有小信封的」。

**紙托與標籤＝專案狀態**
用手寫標籤呈現 `Signature`、`Experiment`、`Classic`，而不是把成熟度硬塞進甜點本體。

整體畫法我會選：

- 暖棕色鉛筆線，不用純黑。
- 粉彩、水彩或廣告顏料般的不均勻著色。
- 三種略有不同的馬卡龍基礎輪廓，避免十顆像換色複製。
- 厚餡、稍微歪掉的殼、散落糖粒與烘焙紙，保留照片裡最迷人的「真的有人做過它」的感覺。
- 不要做成過度精緻的法式精品向量圖，那會少掉你的溫度。

# 品牌已經成熟的四顆招牌款

## 1. Frozen Rabbit Workshop
### 主推口味：**開心果・青檸・白巧克力**

**外觀**

- 外殼使用柔和薄荷綠 `#52A890`。
- 表面撒少量青檸糖粒 `#DCE775`。
- 內餡是厚實的暖白色奶霜，中間夾一條半透明青檸果凍。
- 頂部插一小片手繪糖牌：備料清單、打勾方框或迷你鐵砧。
- 餡料不要只是平滑一圈，而要切成幾段整齊的擠花，像素材被分類完成。

這個專案會把大型製作目標拆成購買、製作、採集、庫存，並整理預算、時間與待辦；所以它應該是一顆**看起來清楚、實用、準備充分的甜點**。repo 目前也確實採用完整的 soft-green 與 lime-green 色系。

**備選口味：**青蘋果香草、開心果海鹽。

## 2. Frozen Rabbit Tome
### 主推口味：**深焙抹茶・柚子金砂**

Workshop 與 Tome 應該一眼就能看出是姊妹專案，但不能只是同一顆換裝飾。

**外觀**

- 使用同一套 Frozen Rabbit 綠色，但殼改成較深的 `#2D6A5A` 或 `#1B4137`。
- 下殼可留一點較淺的 `#75BFA9`，維持家族辨識。
- 內餡擠成一層層薄頁狀，像一本翻開的秘笈。
- 中央放一小條亮柚子凝膠，作為求解結果或最佳路徑。
- 表面用極細糖線畫出分岔又收束的決策樹，並撒少量金砂。
- 可放一片小葉子與一顆礦石糖，分別代表園藝與採掘。

Tome 的核心是策略推薦、機率比較、模擬、收藏品判斷與藏書庫，氣質應該比 Workshop 更深、更安靜、更像一本需要慢慢讀的書。它與 Workshop 現在共用同一套 soft-green 品牌語彙，正適合做成同系列不同焙度。

**備選口味：**鼠尾草青梅、抹茶檸檬白巧。

## 3. Boundary Notes
### 主推口味：**黑醋栗・玫瑰伯爵**

這顆會是整盒裡最成熟、最安靜，也最有故事性的一顆。

**外觀**

- 外殼使用深酒紅 `#8F3D52`，陰影落到天鵝絨紫黑 `#2F1A25`。
- 內餡是淡玫瑰色 `#D99A9A` 與暖象牙色 `#F6E8DF`。
- 餡料正中央放一條極乾淨、清楚的黑醋栗果膠線——直接把「界線」變成甜點的結構。
- 頂部放一枚小小金色 `#B99055` 蠟封，圖案是兔耳、信封或折起來的祕密檔案。
- 外殼可以有一條細緞帶，但不要用鎖鏈、皮革、項圈或鞭子等直白符號。

我會很明確地避開俗套的「黑紅 BDSM 風」。Boundary Notes 的 repo 一直在描述安靜、私密、慢慢整理感受與界線的地方；它的現有品牌也是酒紅、玫瑰、暖紙色與金色，而不是侵略性的色情符號。

**備選口味：**櫻桃黑巧玫瑰、無花果伯爵茶。

## 4. Emu Rabbit GitHub io
### 主推口味：**暮色杏桃・蜂蜜玫瑰**

這不是工具型專案，而是「你本人」的那顆，所以應該是整盒裡最有居住感的甜點。

**外觀**

- 外殼是夜色紫 `#1F1626`，而不是純黑。
- 餡料使用暖奶油白 `#FFF8EE`。
- 正中央是一小塊半透明的杏桃蜂蜜果醬 `#F2BE7B`，像窗裡透出的燈光。
- 表面有玫瑰粉 `#D89A9D` 與一兩片苔蘚綠 `#9FB79A` 糖葉。
- 一側畫一扇微微打開的窗，窗邊露出白色垂耳兔的耳朵。
- 不必放 GitHub Logo；這顆講的是你，不是平台。

個人站的 repo 將它描述為窗邊手記：寫程式、存錢、約會、遊戲、愛、自由與誠實，被溫柔地放在光裡。現有配色也正是夜色、玫瑰、苔綠與琥珀。

**備選口味：**蜂蜜無花果、杏桃玫瑰烏龍。

# 技術與實驗特調

## 5. LinkArray
### 主推口味：**黑白芝麻・鹽焦糖**

**外觀**

- 上殼是白芝麻象牙色，下殼是黑芝麻炭灰色，代表 Array 與 Linked List。
- 內餡不是完整的一圈，而是一顆顆交替排列的芝麻奶霜珠。
- 糖珠之間用細焦糖環彼此串接，像雙向鏈結。
- 表面前半稍微散亂，後半排得非常整齊，表現 `refactor` 前後的差異。
- Hover 時，散亂的糖珠慢慢重排成連續陣列，這會是一個非常漂亮而且有內容的互動。

LinkArray 本身正是嘗試把動態陣列與雙向 Linked List 的優點結合，並透過 refactor 重新整理內部排列；這顆最適合用雙色、鏈結與重排來說故事。

**備選口味：**咖啡牛奶脆珠、伯爵可可焦糖。

## 6. nAnB
### 主推口味：**藍莓優格・葵花子**

這顆應該保留它有點嘴壞、有點可愛的鼠鼠個性。

**外觀**

- 主殼使用聊天室靛藍 `#5663E9`，下殼使用原本的深灰 `#353535`。
- 內餡是白色優格奶霜。
- 中央放兩種小糖珠：綠色代表 A，黃色代表 B。
- 頂部擺一塊寫著 `2A1B` 的小方糖牌。
- 餡中央做成夢夢黃金鼠的臉，參考照片右側那顆動物臉馬卡龍；旁邊撒幾片葵花子焦糖碎。
- 小小的三點輸入動畫可以在 hover 時出現：`● ● ●`。

repo 裡的主角正是夢夢，整個遊戲被包裝成聊天室；A 表示位置與數字都正確，B 表示數字正確但位置錯誤。現有介面也使用 Discord 式藍色通知與深灰背景。

**備選口味：**藍莓乳酪焦糖瓜子、黑芝麻藍莓。

## 7. Vue Router Rule
### 主推口味：**青葡萄・荔枝・紫羅蘭**

**外觀**

- 外殼採用 Vue 系列的清新綠色。
- 餡料是淡紫羅蘭與荔枝白。
- 表面用彩色糖線畫出一條會分岔、判斷，再重新匯合的路線圖。
- 路線節點可用小圓糖表示「允許」「拒絕」「重新導向」。
- 頂部保留 repo 裡原有的獨角獸識別：一根很小的珠光糖角與淡淡彩虹碎屑。
- 不建議只貼一個 Vue Logo；獨角獸與路線規則才是這個專案真正獨有的記憶點。

這個套件的價值是把複雜、難讀、難維護的 `beforeEach` 導航規則重新表達得清晰，而 README 也已經把獨角獸當作主要視覺。

**備選口味：**開心果葡萄蘇打、荔枝蝶豆花。

## 8. Dandelifeon
### 主推口味：**蒲公英蜜・青蘋果**

**外觀**

- 上殼是蒲公英黃，下殼是植物綠。
- 餡是蜂蜜奶霜，中央夾一小塊酸青蘋果果凍。
- 表面排列一塊由方形糖片組成的小棋盤，呈現演算法搜尋與排列。
- 一側長出蒲公英花瓣，另一側飄出一兩顆種子。
- 中間放一顆發光感的藍綠色糖珠代表 mana。
- 頂部三顆不同形狀的糖粒，可分別代表隨機、模擬退火與基因演算法。

這個專案使用三種演算法尋找 Botania 中 Dandelifeon 的最大 mana 產量，所以它很適合成為一顆「植物外觀、演算法內核」的實驗甜點。

**備選口味：**檸檬羅勒蜂蜜、青蘋果香草。

# 早期的小點心

## 9. 75 Alcohol
### 主推口味：**白葡萄・檸檬蘇打**

當然不是酒精口味，兔兔甜點店還沒有失控到那裡。

**外觀**

- 上殼純白，下殼淡水藍。
- 餡料由透明白葡萄果凍與淡藍檸檬奶霜組成，兩種比例可以很清楚地看見。
- 表面畫量杯刻度，但不要固定畫成某個比例，因為原始酒精濃度會改變結果。
- 頂部放一滴透明糖珠與迷你滴管。
- `75%` 可以做成手寫的小標籤，像實驗室瓶身上的貼紙。
- Hover 時讓透明餡與藍色餡的比例滑動，再停在計算結果。

專案原本就是依來源濃度與指定用量推算酒精、水與總量，也另有最終濃度模擬器，所以視覺關鍵是「兩種液體、刻度、比例」，不是醫療紅十字。

**備選口味：**柚子薄荷、青蘋果氣泡。

## 10. 50 Hiragana Test
### 主推口味：**櫻花牛奶・紅豆**

**外觀**

- 上殼淡櫻花粉，下殼米白。
- 內餡是牛奶奶霜，中間只有一小點紅豆餡。
- 表面用巧克力或糖霜手寫一個 `あ`，每次 hover 可以換成不同假名。
- 一旁插一小張方格練習紙糖片。
- 裝飾保持單純，不必硬塞五十個字；它本來就是一個輕巧的練習工具。

repo 的定位就是用來練習日文五十音的網頁，所以這顆最適合成為簡單、親切、帶一點學生練習簿感的小點。

**備選口味：**抹茶柚子、黑糖焙茶。
